# Başlarken — Fastur Web Ekibi

Bu klasör **www.fastur.com.tr** sitesinin yeni hâlinin kendisidir. İçinde siteyi sizinle birlikte kuracak ve sonra güncelleyecek bir ekip (Claude Code + Codex) var.

## 3 adım

1. **Klasörü yerine koyun.**
   Zip dosyasına sağ tık → **Tümünü ayıkla (Extract All…)**. Çıkan klasörün adı `fastur-web` kalsın.
   Bu klasörü şuraya taşıyın: `C:\Users\<kullanıcı adınız>\Fastur\fastur-web`
   (`Fastur` klasörünü siz oluşturun; `fastur-web` onun içinde dursun.)

   ⚠️ **OneDrive'a eşitlenen yerlere koymayın:** Belgeler (Documents), Masaüstü (Desktop), Resimler. Bu yerler OneDrive ile eşitlenirse GitHub ile birbirine girer.
   Dosya Gezgini'nde sol kenarda klasörünüzün yolunda "OneDrive" yazıyorsa yanlış yerdesiniz.

2. **VS Code'da açın.**
   VS Code → **File → Open Workspace from File…** → `fastur-web` içindeki **`Fastur Web Ekibi.code-workspace`** dosyasını seçin → **Open**.
   Pencerenin üst çubuğu turuncu olur; bu sizin site pencerenizdir.
   Sağ altta eklenti önerisi çıkarsa **Install** deyin.

3. **Claude Code'a "başla" yazın.**
   Soldaki Claude Code panelini açın ve şunu yazın:

   > başla

Ekip size **bir seferde tek adım** söyler. Adımı yapınca **"tamam"** yazın; kontrol edip sıradakine geçer. Takıldığınız yerde ekran görüntüsü atın.

**Şifre, doğrulama kodu ve kart bilgisini ekibe asla yazmayın.** Hiçbir adımda gerekmez; giriş ekranlarına yalnız siz yazarsınız.

**Siteye şimdi bakmak isterseniz:** `docs` klasöründeki `index.html` dosyasına çift tıklayın.
